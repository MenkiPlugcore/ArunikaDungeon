# ArunikaDungeon v0.6.0 — Physical Loot & Loot Frenzy
Development source preview for Paper 1.21.11 / Java 21. Built on v0.5.0, preserving the existing configuration, battle, Shared, Private and ticket foundations. Production entry is still disabled. Do not remove CdrDungeonSpawner, ArunikaDungeonExchange or CdrWaystone/Bedrock.

## What's new
- Immutable loot plans per floor, Shared/Private mode and wave/boss; independent percentage rolls, inclusive integer min/max amounts. Each wave chooses MOB_KILL or WAVE_CLEAR; boss uses BOSS_KILL. Tables remain empty unless configured by admin.
- Physical loot adapter: scatter around killed entity or around configured boss spawn for WAVE_CLEAR, safe loaded blocks only, default pickup delay 3 seconds, session-tagged entity tracking, 45-second final Loot Frenzy phase, eligible participants compete for drops. The Shared 30-minute cooldown starts at boss death, before collection ends. Arena/participant reservations stay held until the end of collection.
- Core suppresses duplicate kill/wave notifications and never retries loot events. Private refunds are refused after a drop has been emitted (or conservatively if the adapter throws): otherwise wave farming + intentional abort could duplicate rewards. Boss victory remains completed even if shutdown occurs during collection.
- Admin command editor: `/adg loot addhand <floor> <mode> <wave-1\|boss> <key> <chance> <min> <max>` saves serialized item data with atomic YAML write and backup; remove/list supported. Changes apply on safe reload, not mid-session. GUI editor deferred.
- Vanilla, serialized held item, unique universal ticket, and legacy token template support; optional reflective ItemsAdder, MMOItems and MythicMobs item-provider adapters. Provider runtime not yet verified. Invalid/unavailable providers log and skip, never create substitute items.
- Limits: 256 globally tracked loot entities by default, hard maximum 32 new entities per trigger, stack by material limit, one existing centralized maintenance pass. No extra per-item scheduler. Caps can truncate rewards, logged; keep drop tables modest. Tagged drops block ordinary hopper pickup, nonparticipant/nonplayer pickup, merge and damage events. External plugins that bypass Bukkit events need separate compatibility testing.
- Direct tracked mob native drops/XP still cleared. Custom Mythic skill drops/summons may bypass these listeners; audit actual boss definitions and external plugins before production. Physical tickets use unique ledger serials; no generic ticket copy via serialized item editor.

## Setup

Admin `/adg preview start` intentionally stays rewardless. Do not use the preview on production.
