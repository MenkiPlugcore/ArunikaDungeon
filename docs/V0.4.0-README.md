# ArunikaDungeon v0.4.0 — Shared Dungeon System
Development preview, Paper 1.21.11 / Java 21; production gateway and rewards remain disabled. Source continued directly from v0.3.0. Do not remove CdrDungeonSpawner, ArunikaDungeonExchange, CdrWaystone or its Bedrock bridge.

## What's new
- Independent FIFO membership per floor (all eligible players in the countdown enter together); no dungeon participant cap. UUID lock covers queued and reserved/active sessions, including Private reservations.
- Countdown reads each existing `shared/settings.yml` (30 seconds default). Players can queue while a floor is fighting or cooling down. New countdown starts only when the floor is available and performance guard passes.
- Shared boss defeat starts a 30-minute absolute UTC timestamp, atomically saved to `data/shared-cooldowns.txt`, restored on startup. Private defeats do not change it. Failed battles do not start a successful-boss cooldown. Queue and active sessions are transient, not resumed on restart.
- Queue, registered active participants, living participants and remaining cooldown/countdown are exposed through admin status and read-only gateway API. Existing gateway API version stays 1 for backwards compatibility; new methods have defaults. No real Waystone route authorization yet.
- Opt-in Shared staging commands (not production access), automatic teleport to configured arena, rollback of successful teleports on partial launch failure, retries after 10 seconds. Disconnect/death/pending return prevent queue entry; invalid waiting members are removed on the next queue poll.
- Existing config migration, old commands, battle engine and offline legacy importer retained.

## Build & test
Run `bash tools/test-core.sh`, `bash tools/test-config.sh`, `bash tools/test-battle.sh`, `bash tools/test-shared.sh` with JDK 21. `tools/test-core.sh <legacy-plugin-root>` adds two archive checks. Fixture codec tests do not verify real YAML parsing.
With Maven and network dependencies, use `bash tools/build-verified.sh` or Windows `powershell -ExecutionPolicy Bypass -File tools/build-verified.ps1`. Expected `target/ArunikaDungeon-0.4.0.jar`. Verify staging against real Paper, MythicMobs, Java and Bedrock before deployment. See docs/BUILD-STATUS.txt for actual build status.

## Setup in isolated staging only
Read `docs/SHARED-GUIDE.md` and `docs/BATTLE-GUIDE.md`. Set `battle-preview: true` and `shared-preview: true` with `foundation-only: true`, configure valid battle arenas and installed MythicMobs IDs, and grant test permission only to test accounts. Config migrations add new keys without deleting previous settings. `/adg shared join queen_bee`, `/adg shared status queen_bee`, `/adg shared leave`. Public Waystone entry stays disabled.
