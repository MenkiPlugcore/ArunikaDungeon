# ArunikaDungeon v0.8.0 — Waystone Gateway & Crossplay
Development preview for Java 21 / Paper 1.21.11. Based on v0.7.0, including Unified Exchange, ticket ledger, Shared and Private, wave/boss engine and physical loot. **Not ready for live use.**

New: opt-in single CdrWaystone Hub adapter, native paginated inventory GUI, private/shared selection, live queue/participants, party invites and ready check, exact session return, arena entry/exit guard, automatic integration config migration. Both original Waystone binaries remain unchanged. See `docs/WAYSTONE-GUIDE.md` for setup and staging checks, `docs/WAYSTONE-AUDIT.md` for findings, `docs/BUILD-STATUS.txt` for actual test/build results. Older guides are retained for module-specific configuration.

Use normal Maven build scripts: `powershell -ExecutionPolicy Bypass -File tools/build-verified.ps1` or `bash tools/build-verified.sh`. Requires Maven and internet/dependency cache, real Paper staging and client tests. No verified JAR included in this source release. Do not uninstall old production plugins.
